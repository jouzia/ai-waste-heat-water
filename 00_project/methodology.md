# Methodology

The project uses a modular, configuration-driven computational framework.

## Modules

1. AI Workload Engine
2. Data-Center Thermal Engine
3. Heat-Recovery Engine
4. Membrane-Distillation Engine
5. Hydraulic and Auxiliary Engine
6. Water-Footprint Engine
7. Scenario and Decision Engine

## Validation hierarchy

- Level 1: equation and unit validation
- Level 2: reproduction of selected literature cases
- Level 3: sensitivity and qualitative behavior validation
- Level 4: selected physical validation where feasible

A physical experiment will not be treated as evidence of industrial-scale performance without appropriate scaling justification.

## Uncertainty

The study will distinguish parameter, measurement, model-form, scenario, and system-boundary uncertainty. Monte Carlo and global sensitivity analysis will be used where parameter distributions can be justified.
