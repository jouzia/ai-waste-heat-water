# Experiment Plan

## Benchmark suite

- BENCHMARK-01 — Literature reproduction
- BENCHMARK-02 — Low-temperature waste heat
- BENCHMARK-03 — Higher-temperature waste heat
- BENCHMARK-04 — High-salinity feed
- BENCHMARK-05 — High cooling burden
- BENCHMARK-06 — Water-stressed geography
- BENCHMARK-07 — Lower water-stress geography
- BENCHMARK-08 — High AI utilization
- BENCHMARK-09 — Low AI utilization
- BENCHMARK-10 — Fully integrated system

## Required analyses

- Baseline without heat recovery
- Waste heat + membrane distillation
- Waste heat + realistic cooling
- Integrated water accounting
- Break-even analysis
- Monte Carlo uncertainty
- Global sensitivity
- Geographic analysis
- Multi-objective trade-offs among water, energy, carbon, and cost where defensible

## Reproducibility

Every experiment should record experiment ID, configuration, random seed, code commit, dataset version, model version, parameter set, timestamp, and output artifact identifiers.
