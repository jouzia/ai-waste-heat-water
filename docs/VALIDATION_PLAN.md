# Validation plan

1. Unit and equation tests: dimensional consistency and limiting cases.
2. Literature reproduction: reproduce selected published relationships and ranges without changing their definitions.
3. Sensitivity and behavior tests: verify monotonic behavior only where theory supports it.
4. Experimental validation: compare selected measured heat-transfer and MD relationships against model predictions.
5. External-validity assessment: document where laboratory-scale results cannot represent an industrial AI data center.

A successful test does not establish that the complete system is realistic. Each module receives its own validation status.
