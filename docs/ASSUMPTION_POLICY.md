# Assumption policy

Every non-measured parameter must carry:
- identifier
- definition
- unit
- numerical value or distribution
- source
- source type
- transformation
- applicability limits
- uncertainty
- validation status

We will not silently substitute convenient values for missing evidence.

When multiple defensible values exist, the repository retains the range or distribution and exposes the choice through configuration.

Unknown is a valid state. A missing parameter is preferable to an invented parameter.
