# Malaguti et al. (2026) AGMD recovery anchor points

**Purpose:** source-transcribed benchmark targets for a future independent implementation of the single-pass recovery calculation. These are values reported in the main article's discussion of Fig. 4, not values generated by this repository's code.

**Primary source:** Malaguti et al., “Waste heat won't make membrane distillation cool: Thermodynamic analysis of cooling and pumping burdens,” *Desalination* 628 (2026), 120039. DOI: https://doi.org/10.1016/j.desal.2026.120039. See Section 3.3 and Fig. 4B.

The article's stated reference conditions include \(\Delta T_{h,in}=5\ ^\circ C\), a cold-stream inlet of 20 °C, and a minimum feasible \(\Delta T_{h,out}=0.5\ ^\circ C\) used to bound the plotted model. The article points to supplementary Eq. S8 for the recovery/outlet-temperature constraint and Eqs. S14–S15 for the Config. 3 relationship between efficiency and temperature differences.

## Reproduction protocol and limitations

1. Preserve the four reported values above as source observations; do not relabel them as simulated results from this repository.
2. Implement the supplement-derived Config. 3 equations in a separate reference path, with explicit units and variable definitions.
3. For each anchor, compute \(R\) without fitting to that anchor, then report absolute error in percentage points and relative error.
4. Predeclare numerical tolerances based on whether the paper reports exact values or rounded figure/readout values. These four anchors are rounded to one decimal percentage point, so exact equality is not an appropriate acceptance criterion.
5. Do not infer the full recovery equation from the four points or from the plotted curves. The main article explicitly defers the derivation to Supplementary Information.
6. A match to these four points is a reproduction check, not empirical validation of the model and not evidence of real-world net-water benefit.
